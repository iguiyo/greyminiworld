# Grey Mini World / 灰色小世界

一个适用于 Minecraft 26.3 的轻量 Fabric 模组，为每根灰色木棍绑定一个独立的 15×15×15 个人空间。

## 环境要求

| 项目 | 版本 |
| --- | --- |
| Minecraft | 26.3 |
| Fabric Loader | 0.19.5+ |
| Fabric API | 0.163.0+26.3+ |
| Java | 25+ |

## 功能

- 灰色方块：内部纯灰色 `#808080`，黑色边框，光照等级 15。
- 灰色方块仅创造模式可破坏，并具有高爆炸抗性。
- 灰色木棍使用原版木棍模型和灰色贴图。
- 每根灰色木棍首次使用时生成唯一空间 ID。
- 同一根木棍始终进入同一个空间，不同木棍对应不同空间。
- 每个空间是 15×15×15 的封闭房间。
- 空间内再次右键同一根木棍可返回主世界出生点。

## 轻量空间实现

模组不会在右键时动态创建服务器维度。所有个人房间位于同一个虚空维度中的不同区域，并通过木棍绑定的唯一空间 ID 隔离。这样可以避免动态创建维度造成的卡顿，同时保证玩家拥有各自的独立储物空间。

## 合成

使用两个下界合金锭竖直摆放：

```text
下界合金锭
下界合金锭
```

产出 1 根灰色木棍。

## 使用

1. 合成灰色木棍。
2. 手持木棍右键进入绑定的个人空间。
3. 在空间内再次右键同一根木棍返回主世界。

木棍的空间 ID 保存在物品数据中。丢弃或交给其他玩家时，空间绑定会跟随该木棍。

## 安装

1. 安装 Minecraft 26.3、Fabric Loader 0.19.5+ 和兼容的 Fabric API。
2. 将 `miniworld-3.0.0.jar` 放入游戏的 `mods` 文件夹。
3. 启动游戏。

## 构建

Windows:

```powershell
./gradlew.bat build
```

Linux/macOS:

```bash
./gradlew build
```

构建产物位于 `build/libs/miniworld-3.0.0.jar`。

## 项目结构

```text
src/main/java/com/miniworld
├── block       灰色方块
├── item        灰色木棍
├── registry    方块与物品注册
└── world       个人空间与传送逻辑
```
